# 05 — Portfolio gallery page

**What to build:** A visitor can browse a full gallery of AJM's type of work, filter it by category, and open a project for more detail — without any fabricated project-specific claims.

**Blocked by:** 01 — Project scaffold & site shell

**Status:** ready-for-agent

- [ ] Shared portfolio/project data model defines project entries by **category only** (e.g. "Residential Brickwork," "Masonry Repointing," "Structural Alteration") with generic descriptive copy about that type of work — no invented addresses, completion dates, or client names
- [ ] `/portfolio` page renders a luxury masonry-style gallery of large cards using Unsplash placeholder imagery
- [ ] Category tags and working filters let a visitor narrow the gallery by category
- [ ] Hover animations on gallery cards (e.g. image zoom, overlay)
- [ ] Clicking a project opens a detail modal with a smooth transition, showing the category and generic descriptive copy
- [ ] Cards animate in as they enter the viewport
- [ ] Fully responsive across breakpoints; modal is keyboard-dismissible and accessible
